# مشروع المخبتين القرآني – مركز كفرأبيل القرآني

منصة متابعة طلاب مشروع المخبتين: صفحة خاصة لكل ولي أمر، ولوحة إدارة للمشرف، مبنية على React + Supabase (قاعدة بيانات ومصادقة حقيقيتان).

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح: http://localhost:5173

للبناء النهائي: `npm run build` (الناتج في `dist/`).

> قبل أول تشغيل لازم تربط المشروع بـ Supabase — انظر القسم التالي.

## إعداد Supabase (مرة واحدة فقط)

1. أنشئ حسابًا ومشروعًا مجانيًا على [supabase.com](https://supabase.com).
2. من **SQL Editor** داخل المشروع، افتح `supabase/schema.sql` من هذا المستودع، انسخ محتواه كاملًا، ونفّذه (Run).
   هذا ينشئ كل الجداول، صلاحيات الوصول (RLS)، وحاويات تخزين الصور. الملف آمن لإعادة التشغيل أكثر من مرة.
3. من **Project Settings → API** انسخ **Project URL** و **anon public key**.
4. انسخ `.env.local.example` باسم `.env.local` وعبّئ القيمتين فيه (هذا الملف لا يُرفع لـ Git).
5. من **Authentication → Users → Add user** أنشئ حساب المشرف (بريدك + كلمة مرور). أول بريد لا يطابق `guardian_email` لأي طالب يصبح تلقائيًا **admin**.
6. سجّل الدخول من الموقع بنفس البريد وكلمة المرور.
7. أضِف الطلاب من **إدارة الطلاب ← إضافة طالب** (الصور تُرفع مباشرة لـ Supabase Storage). لإنشاء حساب ولي أمر: أدخل بريده الحقيقي في حقل "بريد ولي الأمر" بنموذج الطالب، ثم أنشئ له حسابًا من **Authentication → Add user** بنفس البريد — يُربط تلقائيًا بابنه ويصبح دوره **parent**.

## التقنيات

React 18 + TypeScript + Vite + Tailwind CSS + React Router + Lucide Icons + Supabase (قاعدة بيانات، مصادقة، تخزين ملفات).
الخطوط: Tajawal (أوزان 300–800) و Amiri للآيات، محمّلة محليًا عبر `@fontsource` (تعمل بدون إنترنت).
الرسوم البيانية مبنية بـ SVG بدون مكتبات إضافية.

## هيكل المشروع

```
supabase/
  schema.sql           ← الجداول + صلاحيات RLS + المُشغّل التلقائي + حاويات الصور
public/
  images/brand/        شعار المشروع، شعار المركز، صورة المشرف
src/
  data/project.ts      بيانات هوية المشروع الثابتة (الاسم، الشعارات، المشرف)
  lib/supabase.ts      عميل Supabase
  lib/mappers.ts       تحويل بين أعمدة قاعدة البيانات وأنواع التطبيق
  types/               أنواع البيانات (مطابقة لجداول Supabase)
  context/             AuthContext (Supabase Auth) – DataContext (قراءة/كتابة Supabase) – ToastContext
  hooks/               useParentStudent، useSidebarCollapsed
  utils/               تنسيق التواريخ، حساب المعدلات والحضور والعبادات، تاريخ اليوم
  layouts/             Sidebar، ParentLayout، AdminLayout
  components/
    brand/             الخلفية، الشعارات، التذييل
    ui/                عناصر عامة: Avatar، Badge، Modal، Toggle، Progress، ScoreChart ...
    shared/             مكونات مشتركة: جدول العبادات الأسبوعي، تفاصيل يوم الدوام، التقارير
    parent/             مكونات صفحة ولي الأمر
    admin/              نماذج الإدارة
  pages/
    LoginPage.tsx
    parent/             الرئيسية، المطلوب القادم، الحفظ والمراجعة، العبادات، سجل الدوام، التقارير
    admin/              لوحة التحكم، إدارة الطلاب، صفحة الطالب (Tabs)، تسجيل دوام اليوم، الصور والأنشطة، التقارير
```

## تعديل البيانات

كل البيانات (الطلاب، الدوام، العبادات، المطلوب القادم، الأنشطة) تُدار من لوحة الإدارة بالموقع مباشرة، وتُحفظ في قاعدة بيانات Supabase الحقيقية — تظهر لجميع من يفتح الموقع فورًا.
بيانات هوية المشروع الثابتة فقط (اسم المشروع، الشعارات، اسم المشرف وصورته) موجودة في `src/data/project.ts`.

لتعديلات مباشرة على قاعدة البيانات (نادرًا ما تُحتاج): استخدم **Table Editor** أو **SQL Editor** داخل مشروع Supabase.

## معادلة العلامة المقترحة

زر الآلة الحاسبة في نماذج الدوام يقترح علامة اليوم:
حضور 10% + حفظ 30% + مراجعة 30% + عبادات 20% + تقييم 10%
(الدالة `suggestScore` في `src/utils/stats.ts`).

معادلة علامة العبادات نفسها (يومية من 100، وأسبوعية بمتوسط الأيام الستة + مكافأة الصدقة) موجودة في `src/utils/worship.ts`.
